What we install

Networking

Structured cabling, Wi-Fi coverage design, routers, switches and firewalls. We test every cable run and hand you a labelled network diagram.

  • Cat6 / Cat6a cabling and patch panels
  • Business Wi-Fi and guest networks
  • VLANs, VPN and firewall setup

Server installation

Physical and virtual servers set up for file sharing, backups, email or line-of-business software, with monitoring and a tested recovery plan.

  • Windows Server and Linux
  • NAS and automated backups
  • Rack mounting, UPS and cable management

CCTV installation

IP camera systems placed to cover entrances, lots and work areas, with local recording and remote viewing on your phone.

  • Indoor, outdoor and night-vision cameras
  • NVR recorders and cloud backup options
  • Phone and desktop remote access

Intrusion systems

Alarm panels, door and window sensors, motion detectors and sirens, with optional monitoring and alerts to your phone.

  • Keypads, sensors and glass-break detectors
  • Integration with CCTV and access control
  • Maintenance and inspection plans
